# 배전망 위험 지도

2026 빛가람 AI·ICT 경진대회 고등부 프로토타입.
**변압기가 수요를 감당하는가**를 시·군·구로 비교하는 우선점검 지도입니다.

점수는 고장 확률이 아닙니다. 점검 순서입니다.

## 심사 요지

| 질문 | 답 |
| --- | --- |
| 무엇을 푸나 | 사용량이 아니라 설비 여유 부족 |
| 식 | `100 × (0.45 nG + 0.35 nP + 0.20 nR)` |
| AI | 같은 식의 설명 가능 규칙 + 로지스틱 위협 지수. 학습 예측기 아님 |
| 데이터 | 인구는 행안부 2026.07 공표. G·P·R은 변압기 원자료 비공개로 프로토타입 |
| 검증 | 정전 보도 6건을 설비/외인으로 분리. 화재·추돌은 인과 없음 |

## 화면

1. **상황판** 전국 점수, 수요 시나리오 0–200%+
2. **지역** 16개 광역(전남광주 통합) → 229 시군구
3. **상세** 원인 분해, 인구·산업, 위협 AI
4. **방법** 심사 한 장, 산출식, 사고 대조
5. **출처** 원문 링크와 한계
6. 헤더 **시연** 버튼 = 3분 투어

## 식

```
G = (1 + Δ수요) / (1 + Δ설비)
P = 7·8월 / 연평균 월사용
R = 주택용 지수
Ñ = max(0, (X − min) / (max − min))  // 상한 없음
Score = 100 × (0.45ÑG + 0.35ÑP + 0.20ÑR)
위협지수 = 100 / (1 + e^(-(Score−70)/12))
```

수요 +g%일 때 G는 0.85g, P는 0.45g만큼 커집니다.

## 한계 (숨기지 않음)

- 시군구 변압기 용량·부하율은 한전이 공개하지 않음
- 산업용 GWh는 광역 용도 비중 × 인구 배분
- 주택용 지수 R(39–65)은 한전 주택용 판매 비중(약 14%)과 스케일이 다름
- 정전 뉴스 n=6, 원인 혼재. Spearman은 참고
